## 📖 About

This repository is a comprehensive collection of practice exercises, mini-projects, and real-world UI builds created while learning modern web development from scratch. It covers the complete frontend-to-backend stack — from semantic HTML and responsive CSS to React components, Node.js fundamentals, and SQL queries.

> **Goal:** Build strong fundamentals that power production-grade projects.

## 📁 Repository Structure

```
Web-Dev-Foundations/
│
├── HTML/                    # Semantic markup, forms, tables, accessibility

├── Node.js/
```
